# 无穹55 · 小窝 🏠

无穹55班的班级网站。不是谁一个人的网站，是咱们一起的小基地、小门面、小回忆收容所。

当前是 **纯前端演示版（v1）**：全部功能可以在浏览器里直接用，数据存在访问者自己的浏览器（localStorage）里。

## 怎么打开

**方式一（最快）**：直接双击 `index.html` 用浏览器打开。

**方式二（推荐）**：在本目录起一个本地服务器：

```bash
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 功能一览

| 页面 | 文件 | 功能 |
|---|---|---|
| 🏠 首页 | `index.html` | 活动倒计时（可管理）、生日提醒、今日份小确幸、最新动态、小窝大数据 |
| 📸 照片墙 | `photos.html` | 分类（合照/活动/日常/表情包）、瀑布流、上传（自动压缩）、点击放大 |
| 💬 留言板 | `messages.html` | 气泡在页面上飘来飘去，点气泡看全文，支持匿名 |
| 📮 匿名提问箱 | `askbox.html` | 完全匿名提问 + "同想知道"投票；班主任/辅导员凭**口令**解锁回答模式（默认口令 `wq55`，班委可在解锁弹窗里修改） |
| 🌿 日常分享板 | `daily.html` | 话题标签、配图、点赞、评论、**匿名树洞**模式 |
| 🧩 组队邀请板 | `teams.html` | 发布招募、类型筛选、报名进度条、截止倒计时、满员庆祝 |
| 📚 经验分享帖 | `experience.html` | 学习/竞赛/选课/科研/生活分类、全文阅读、"有用"点赞 |
| 🏆 荣誉墙 | `honors.html` | 荣誉时间线、添加荣誉（自动撒花） |
| 👥 同学们 | `members.html` | 每人一张成员卡：头像、一句话介绍、标签、**🔗 个人主页链接**（GitHub/博客/主页都可以挂） |

**🎨 个性化**：导航栏右上角 ⚙️ 可以——
- 换主题色（珊瑚橙/湖水青/樱花粉/葡萄紫/薄荷绿）
- 界面明暗：跟随壁纸（深色壁纸自动切整套深色界面，自定义图片按亮度自动判断）/ 浅色 / 深色
- 换壁纸（预设渐变 / 上传图片 / 粘贴链接）+ 卡片透明度 + 壁纸遮罩 + 毛玻璃
- **首页横幅三模式**：🌈 跟随主题色 / 🧑‍🤝‍🧑 **全班名字云**（名字来自成员墙，新同学上墙自动飘进横幅）/ 🖼️ 自定义照片（自动加遮罩保证文字可读）

配置存在本机浏览器，每人都能装修自己的小窝。

**🎉 emoji 迸发**：发布动态、上传照片、加入队伍、老师回答问题……完成动作时会有对应 emoji 从底部蹦出来（自研零依赖实现，参考 GitHub 合并 PR 的 emoji 雨）。

**小彩蛋** 🐲：快速点页面左上角 Logo 五次，会有神秘访客出现。

## 数据说明（重要）

v1 的所有数据（发布的动态、上传的照片等）都存在**当前浏览器**的 localStorage 里：

- 换一台电脑 / 换一个浏览器，看到的是初始示例数据；
- 清除浏览器数据后，自定义内容会消失，示例数据会重新出现；
- 照片上传前会自动压缩，但 localStorage 总共约 5MB，存太多照片会提示空间不足。

所以 v1 适合：**本机演示、设计讨论、一起决定还要加什么**。

## 如何修改示例数据

所有示例内容集中在 `js/seed.js`（成员、生日、活动、照片、留言、动态、组队、经验帖、荣誉）。
改完后在浏览器控制台执行 `WQ.resetAll()` 再刷新，即可重新载入新种子。

## 如何分享给全班（部署）

任意静态托管都可以，推荐 GitHub Pages：

1. 把本目录推到一个 GitHub 仓库；
2. 仓库 Settings → Pages → 选择 `main` 分支 / root；
3. 把 `https://你的用户名.github.io/仓库名/` 发到班群。

（校内服务器、腾讯云 COS 静态托管等也都可以，整套网站就是纯 HTML/CSS/JS，零依赖、无构建。）

## 升级路线（v2 想法）

当大家真的要"共用一个网站"时，加一个后端让数据互通：

- 方案 A：Node.js（Express）+ SQLite，部署在一台小服务器上；
- 方案 B：LeanCloud / Supabase 等 BaaS，免服务器；
- 前端页面基本不用改，把 `js/common.js` 里的 `WQ.get/WQ.set` 换成 API 请求即可；
- 顺带做：学号+密码或邀请码登录、图片存对象存储、管理员审核。
